PACMAN - QUICK START

Launch the pac-man executable. The packaged game loads its bundled
configuration automatically.

Controls
- Arrow keys: move Pacman
- Escape: pause or return
- Enter: confirm a menu choice

Evaluator cheats (enabled in the packaged configuration)
- I: invincibility
- F: freeze ghosts
- L: complete the current level
- +: add one life
- S: double Pacman's speed

Highscores are stored in the current user's application-data directory.
