# Ghost AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four testable BFS-driven ghosts, frightened behavior, collisions, life loss, scoring, and delayed respawn to the existing game engine.

**Architecture:** `Ghost` contains the common movement and BFS logic while the four colored subclasses only define identity and home corner. `GameState` initializes and updates ghosts, activates frightened mode, and owns collision consequences. `Pacman` only notifies `GameState` when a super-pacgum is consumed.

**Tech Stack:** Python 3.13, Pydantic 2, pytest, Flake8, mypy, existing A-Maze-ing adapter.

## Global Constraints

- Keep gameplay logic independent from Pygame rendering.
- Use the existing pixel-coordinate rail and `MazeSquare` wall model.
- Use one shared BFS behavior for all four ghosts.
- Do not modify sprites, audio, documentation outside this plan, packaging, or deployment.
- Do not push changes to a remote repository.

### Task 3: Collision consequences and update loop

**Files:**
- Modify: `pacman/game/state.py`
- Test: `tests/test_ghosts.py`

**Interfaces:**
- Consumes: `GhostMode`, `Ghost.update()`, Pacman's `is_dying`, configured ghost points, and `UpdateResult`.
- Produces: one collision-resolution pass per frame and `UpdateResult.LOSE` when no lives remain.

```python
def __resolve_ghost_collisions(self, now: float) -> UpdateResult: ...
def update(self, now: float | None = None) -> UpdateResult: ...
```

- [ ] **Step 1: Write failing collision tests**

Test normal contact removing exactly one life and setting `is_dying`, repeated
contact while dying having no effect, frightened contact adding exactly
`points_per_ghost`, eaten contact having no effect, and zero lives returning
`LOSE`.

- [ ] **Step 2: Run collision tests and confirm failure**

Run: `.venv/bin/python -m pytest tests/test_ghosts.py -k 'collision or lose' -v`

Expected: lives and ghost modes remain unchanged.

- [ ] **Step 3: Implement collision resolution**

Treat entities as colliding when both axis distances are at most one third of
the current cell width. Ignore eaten ghosts and all contacts while Pacman is
already dying. Apply score or life consequences once.

- [ ] **Step 4: Update all entities each frame**

In `GameState.update(now=None)`, update Pacman, update every ghost with the same
monotonic timestamp, resolve collisions, and return `LOSE` at zero lives or
`CONTINUE` otherwise.

- [ ] **Step 5: Run all ghost tests**

Run: `.venv/bin/python -m pytest tests/test_ghosts.py -v`

Expected: all ghost and collision tests pass.

- [ ] **Step 6: Commit collision integration**

